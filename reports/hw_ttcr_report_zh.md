# 實驗報告：硬體測試時計算路由器 (HW-TTCR)

## 摘要
隨著 System 2 思考型模型（如 OpenAI o1, DeepSeek-R1）在邊緣裝置的普及，系統需在推論時動態決定 Token 是要直接輸出，還是要展開蒙地卡羅樹搜尋 (MCTS) 進行深度思考。傳統上這需要不斷進行 CPU-GPU 同步，造成極大延遲。本實驗提出 HW-TTCR，將信心度閾值判斷與搜尋觸發邏輯直接實作於 NPU 輸出端硬體中。

## 實驗結果
- **Baseline 延遲 (軟體 MCTS 路由):** 512.00 ms (1024 tokens)
- **HW-TTCR 延遲:** 2.05 ms
- **加速比:** 250.00x

## 架構建議
建議將「硬體測試時計算路由器 (HW-TTCR)」整合至 Edge NPU 的調度器中，使其能原生支援 System 2 推論，實現無 CPU 介入的動態思考時間擴展，大幅提升邊緣 AI 代理 (Agentic AI) 的反應速度與邏輯處理能力。
