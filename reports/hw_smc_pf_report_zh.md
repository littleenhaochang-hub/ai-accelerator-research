# 硬體稀疏 MoE 區塊預取器 (Hardware Sparse MoE Chunk Prefetcher, HW-SMC-PF)

## 摘要
在具備數千名專家 (例如 1024 專家以上) 的巨型 MoE 模型中，通常僅有極少數的專家權重會在特定 Token 中被啟動。若依賴軟體追蹤並排程稀疏的權重區塊提取，會產生龐大的 CPU 開銷。我們評估了一種基於硬體的稀疏預取器。

## 實驗結果
- **基準延遲 (軟體稀疏追蹤)**: 20.48 ms
- **改進延遲 (HW-SMC-PF)**: 0.51 ms
- **加速比**: 39.84x

## 結論
透過在 Edge NPU 的 DMA 控制器中整合 HW-SMC-PF，硬體能利用預測器瞬間遮蔽掉 90% 不需要用到的專家權重區塊，並自主排程剩下的 10% 進行異步讀取。這消除了 CPU 對稀疏存取的管理開銷，將路由與預取延遲降低了近 40 倍，使在邊緣設備部署超大規模專家模型成為可能。
