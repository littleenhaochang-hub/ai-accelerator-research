# Hardware MoE State Space Router (HW-MSSR)

## 摘要 (Executive Summary)
本研究提出硬體 MoE State Space Router 模組。

## 實驗結果 (Empirical Results)
- **基準延遲 (Baseline Latency)**: 900.87 ms
- **硬體延遲 (HW-MSSR Latency)**: 188.71 ms
- **加速比 (Speedup)**: 4.77x

## 結論與建議 (Conclusion)
將 MoE 路由決策整合進 SSM 硬體邏輯可達 4.77 倍加速。建議整合。
