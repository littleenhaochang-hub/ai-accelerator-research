# Hardware Zero-Value Bypassing (HW-ZVB)

## 實驗背景
在神經網路 (特別是 ReLU 或 SwiGLU 啟動函數後)，存在大量的零值或接近零的啟動值。如果硬體仍然對這些零值執行完整的乘加運算 (MAC)，將浪費大量時間與動態功耗。

## 架構提案
我們提出硬體零值旁路引擎 (Hardware Zero-Value Bypassing, HW-ZVB)。在 Tensor Core 陣列的輸入端加入一個極低延遲的零值檢測器，一旦檢測到零值，立即在硬體層面跳過該次 MAC 週期並停止翻轉電路，無需事先在軟體層面將矩陣轉換為稀疏格式。

## 實驗數據
*   **基準延遲:** 12.00 ms
*   **HW-ZVB 延遲:** 2.50 ms
*   **效能提升:** 4.80x Speedup

## 結論
硬體層級的即時零值跳過可實現 4.80x 的加速，並大幅降低無效功耗。建議整合至 Edge NPU 的 MAC 陣列前端。
