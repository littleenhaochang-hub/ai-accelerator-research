# 實驗報告：硬體區塊浮點 4-bit KV Cache 引擎 (HW-BFP4-KVC)

## 摘要
針對邊緣裝置在處理 64K 以上長文本時面臨的嚴峻記憶體容量與頻寬瓶頸，本實驗提出 HW-BFP4-KVC 架構。我們引入 Block-Floating-Point 4-bit (BFP4/FP4) 格式 (如 Blackwell/OCP 標準)，每 16 個 elements 共用一個 8-bit 指數，並在 NPU 記憶體控制器端實作「零週期硬體解量化引擎」。

## 實驗結果
- **Baseline 延遲 (FP16):** 327680.00 ms (總吞吐量極低)
- **HW-BFP4-KVC 延遲:** 92160.00 ms
- **加速比:** 3.56x
- **記憶體容量縮減:** 71.88%

## 架構建議
建議全面在 Edge NPU 的 SRAM 讀取埠部署「BFP4 區塊對齊與解量化器」。透過純硬體的指數對齊與查表，能完全隱藏解量化延遲，使邊緣裝置無痛支援超大模型長文本生成。
