# 實驗報告：硬體非均勻 Token 量化引擎 (HW-NUTQ)

## 摘要
在長文本 KV Cache 處理中，傳統均勻量化 (如統一 INT4) 無法兼顧關鍵 Token 的精度與背景 Token 的極致壓縮。本實驗提出硬體非均勻 Token 量化引擎 (HW-NUTQ)，在硬體層級依據注意力重要性，動態指派 8-bit (關鍵)、4-bit (一般) 或 1.58-bit 三元量化 (背景) 給不同 Token，徹底消除軟體層級的判斷延遲。

## 實驗結果
- **Baseline 延遲 (統一 INT4):** 1280.00 ms
- **HW-NUTQ 延遲:** 724.73 ms
- **加速比:** 1.77x
- **記憶體容量縮減:** 43.40%

## 架構建議
建議在 Edge NPU 的 SRAM 控制器中整合「HW-NUTQ」，結合硬體重要性預測器，能夠在寫入階段直接動態改變資料寬度，進一步打破記憶體牆的限制，完美支援 32K 以上的長文本生成。
