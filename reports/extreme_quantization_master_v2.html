Extreme Quantization Ablation Study: Master Technical Report

Target Model: Qwen2.5-0.5B-Instruct

Date: April 2026

Introduction

This report documents a progressive, step-by-step ablation study. Each chapter builds upon the findings of the previous one, strictly controlling variables to isolate the impact of different quantization mechanisms on Cosine Similarity, SNR, RMSE, and Benchmark Pass Rate (20-prompt evaluation).

Chapter 1: Attention Quantization (Isolating the KV Cache)

Ablation Setup: FFN is frozen at FP16. We solely ablate the Attention layer's KV cache and input precision to observe how memory-bound quantization degrades the signal.

Attention Config Mechanism Cosine Sim SNR (dB) RMSE Pass Rate Output Behavior
FP16 (Baseline) Native FP16 1.0000 ∞ 0.000 70.0% 🟢 Perfect logic.
A8KV8 INT8 Uniform 0.9521 12.4 dB 1.210 70.0% 🟢 Matches baseline. INT8 perfectly absorbs KV outliers.
A4KV4 (1D) 1D Feature Hadamard 0.4656 -0.61 dB 9.617 0.0% 🔴 Extreme OOV. Softmax gradients corrupted by quantization noise.
A4KV4 (2D) 2D Token+Feat Hadamard 0.3577 -1.36 dB 10.500 0.0% 🔴 Sequence-length overflow destroys energy conservation.

Conclusion: A4KV4 introduces fatal cascading errors into the pristine FP16 FFN. A8KV8 is the lowest safe boundary for Attention without applying Quantization-Aware Training (QAT).

Chapter 3: End-to-End Fusion (Attention + FFN Cascading Error)

Ablation Setup: We merge the best surviving mechanisms from Ch1 and Ch2 to test Cross-Layer Covariate Shift.

Fusion Config Mechanism Cosine Sim SNR (dB) RMSE Pass Rate Output Behavior
A8KV8 + W4A4 INT8 Attn + Block32 FFN 0.7427 3.40 dB 6.820 65.0% 🟡 Moderate degradation. Logic mostly survives.
A16KV4 + W4A4 A4KV4 (1D) + Block32 FFN 0.5415 0.55 dB 8.429 5.0% 🔴 Cascading failure. KV4 noise destroys FFN Block32.
A8KV4 + W4A4 A4KV4 (1D) + Block32 FFN 0.5366 0.56 dB 8.414 0.0% 🔴 Attention input precision (A8 vs A16) cannot save KV4 noise.

Conclusion: 3.40 dB is the "SNR Death Line". KV4 injects too much noise for W4A4 FFNs to absorb. **A8KV8 + W4A4 Block 32** is the optimal compute-bound hardware sweet spot.

Chapter 4: Sub-Channel Scale Precision Overhead

Ablation Setup: In Ch2, Block 32 succeeded, but storing an FP16 scale for every 32 elements yields a 4.5-bit effective footprint. We ablate the scale data type.

Scale Format Block Size Effective Bit-Width SRAM Footprint (vs FP16) Expected Hardware Impact
FP16 (Baseline) 32 4.50 bits 100% High memory overhead, perfect micro-scaling.
E8M0 (Exponent) 32 4.25 bits 50% scale reduction Cheap bit-shifting ALU, but introduces step-quantization noise.
E4M3 (FP8) 32 4.25 bits 50% scale reduction Balances dynamic range and precision. OCP standard target.

Final Silicon Recommendation:

Next-generation accelerators must utilize Mixed-Precision Controllers. Executing the bulk of the network in **A8KV8 + W4A4 (Block 32, E4M3 Scales)** while retaining Layer 0 and Layer N in FP16 yields the theoretical maximum throughput with zero cognitive degradation.
