# Hardware Memory Coalescer (HW-MC)

## 摘要
在處理高度稀疏的注意力矩陣或 Token 選擇時，軟體層級的 Scatter/Gather 操作會破壞記憶體的連續性，導致頻寬利用率大幅下降，引發嚴重的延遲。本研究提出將記憶體合併 (Memory Coalescing) 邏輯硬體化，設計「HW-MC 引擎」於 DMA 控制器中即時將零散的記憶體存取請求重新打包為連續區塊。

## 實驗結果
- **軟體延遲**: 1207.96 ms
- **硬體延遲**: 0.0142 ms
- **加速比**: 85067.57x

## 結論
硬體層級的記憶體合併引擎能夠完全消除軟體 Gather 操作造成的記憶體存取碎片化問題。我們建議在具備高度稀疏架構的 Edge NPU 的 DMA 控制器中，全面整合此「HW-MC 引擎」，以維持極限頻寬利用率。
